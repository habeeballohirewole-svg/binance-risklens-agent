# RiskLens Demo

## Binance Agent OS Mini Hackathon — Track A

RiskLens is an AI market-research agent built with Binance Agent OS.

### Demo workflow

1. Connect to Binance Agent OS.
2. Request live BTCUSDT market data.
3. Analyze 15m, 1h and 4h timeframes.
4. Evaluate trend, momentum, structure and volatility.
5. Generate a setup score.
6. Identify key levels and invalidation.
7. Provide a risk assessment.
8. Allow a WAIT / NO-TRADE decision when there is no clear edge.

### Demo prompt

Run RiskLens analysis on BTCUSDT using 15m, 1h and 4h. Retrieve live Binance data, analyze the market structure, momentum, key levels and risk, then give me a setup score and invalidation condition.

### Key idea

RiskLens does not force a trade.

It turns market noise into a structured decision brief and makes risk awareness part of the workflow.
